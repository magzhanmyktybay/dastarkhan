# DASTARKHAN – FINAL PROJECT REPORT

## 1. Introduction

Our project is called Dastarkhan. It is a restaurant website designed to provide users with information about food, meals, recipes, and restaurant services.

The main goal of our project is to create a simple, attractive, and user-friendly website. Users can explore the menu, search for meals, view recipes, and find useful information about the restaurant.

## 2. Project Structure

Our website contains seven HTML pages connected through a navigation bar. All pages have a consistent design and style.

The project uses:
- HTML5 for the website structure.
- CSS3 for design and layout.
- JavaScript for interactive features.
- jQuery for the FAQ section.
- TheMealDB API for meal and recipe information.

## 3. Implemented Features

The website includes the following features:

- Navigation between different pages.
- Responsive website design.
- Light and Dark Theme.
- User registration and sign-in interface.
- Interactive FAQ section.
- Meal search functionality.
- Food categories and filters.
- Random meal selection.
- Recipe information with ingredients and cooking instructions.
- Image gallery and other interactive elements.

## 4. Individual Contributions

Each group member was responsible for different parts of the project.

### Van Alexander – jQuery and API Integration

My responsibility was implementing the jQuery functionality and API integration.

For the jQuery part, I worked on the FAQ section. It contains six frequently asked questions. When users click on a question, the answer opens or closes using the jQuery slideToggle() function. I also added smooth animations and plus/minus indicators.

For the API part, I worked with TheMealDB API. I used JavaScript fetch() to receive data in JSON format. The API allows users to search for meals, filter meals by category, view random meals, and see recipe information, including ingredients and cooking instructions.

### Adilzhan – Light/Dark Theme and Sign-in

Adilzhan was responsible for the Light and Dark Theme functionality and the sign-in system.

His work included implementing theme switching, saving the selected theme in localStorage, and developing user authentication functionality.

### Magzhan – Website Development and Other Features

Magzhan was responsible for the main website development and the remaining features.

His work included creating the website pages, HTML structure, CSS styling, navigation, responsive design, registration interface, and other website functionality.
